## Відповідність станів

| Тип | Внутрішній стан | Стан для користувача |
| --- | --- | --- |
| Product | draft | Чернетка |
| Product | active | Активне |
| Product | paused, sold, expired | Неактивне |
| Buy Request | open, partially_selected, partially_completed, partially_fulfilled | Активне |
| Buy Request | completed, fulfilled, cancelled, expired | Неактивне |

Product підтримує збережені чернетки; Buy Request окремого стану чернетки не має. Вкладки товарів: активні, неактивні, чернетки, усі; запитів: активні, неактивні, усі. Лічильники обчислюються після завантаження всіх сторінок власних записів.

## Дії та бізнес-правила

Сервер Product і надалі приймає всі допустимі значення статусу без додаткових обмежень переходів. Користувач прямо попросив зберегти повторну активацію sold. Картка пропонує основну дію та інші чинні переходи. Buy Request власник може закрити через cancelled або expired; повторне відкриття цим API не підтримується.

Обране зберігає і показує неактивні записи; якщо повний перегляд недоступний за чинними правилами, показуються назва, статус і видалення. Чужі чернетки не показуються. Доступ за прямими посиланнями не змінено. Пошук і мапа використовують існуючі серверні фільтри активних станів. Код Seller Offer, Deal, Review, підписок і сповіщень не змінено. Міграцій немає.
