# Навпаки: гайд для тестувальника пілота

## Мета

Перевірити, що реальна угода проходить шляхом: попит → пропозиція →
переговори → вибір → замовлення → завершення → відгук.

## Сценарій для двох людей

1. Покупець створює запит із кількістю, бюджетом, геозоною та строком.
2. Продавець створює офер; за потреби прив'язує активний товар.
3. Обидві сторони відкривають чат по оферу й узгоджують деталі.
4. Покупець приймає всю або частину кількості оферу.
5. Продавець переводить замовлення у `in_progress`.
6. Покупець підтверджує `completed` і обидві сторони залишають відгук.

## Що повідомити команді

- крок, де ви зупинилися;
- текст помилки або скриншот без приватних даних;
- чи отримали ви релевантний офер;
- скільки часу зайняв шлях до першого оферу;
- що було незрозумілим у формі або статусі.

Не надсилайте в зворотному зв'язку пароль, повну адресу, номер телефону чи
платіжні дані.
