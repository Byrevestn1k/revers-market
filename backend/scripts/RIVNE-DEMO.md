# Тестові продавці в Рівному

Набір `rivne-demo-v1` містить по 10 продавців для 18 основних розділів.
Кожен має 2–10 активних оголошень, відповідні тематичні фото, унікальну синтетичну адресу в Рівному та координати поблизу обраної вулиці.

Логіни: `ТестерПродавець1` … `ТестерПродавець180`.
Пароль для тестових облікових записів: `TesterRivne2026!`.
Пошта має домен `rivne-demo.example.invalid`, а телефони використовують несправжній код `+38000`.
Ці адреси не описують справжніх мешканців; точні адреси профілю не розкриваються на мапі.
Українські логіни створюються через seed; звичайні правила реєстрації не змінені.

## Відтворення

Команди з кореня проєкту:

```powershell
node backend/scripts/seed-rivne-demo.mjs                 # попередній підрахунок
node backend/scripts/seed-rivne-demo.mjs --check-photos  # перевірка доступності фото
node backend/scripts/seed-rivne-demo.mjs --apply         # створити набір
node backend/scripts/verify-rivne-demo.mjs               # перевірити дані й API запущеного бекенду
```

Повторний запуск не дублює створені оголошення і не перезаписує паролі чи профілі.
Набір записується однією транзакцією. Чужі облікові записи з таким самим логіном не перезаписуються.
Для розширення на всі категорії та підкатегорії використовуйте `--all --apply`; це значно більший набір.

## Перевірка на екрані

1. Відкрити http://127.0.0.1:5173/ та обрати місто «Рівне».
2. Обрати категорію або підкатегорію. Пошук підтримує назву товару та логін продавця.
3. На мапі натиснути «Рівне», обрати «Продавці та їхні товари».
4. Натиснути зелений кружок. Число — кількість продавців у цій приблизній точці. У списку видно товари, які відповідають поточним фільтрам.
5. Перемкнути перегляд на «Окремі товари», щоб зберегти звичний спосіб перегляду оголошень.

Для тестування локально запущених сервісів додаткові зміни залежностей і схеми бази не потрібні.

Тематичні фотографії: https://unsplash.com/ (URL збережені в `rivne-demo-catalog.mjs`, доступність перевіряється окремою командою).
Назви вулиць звірені з переліком Рівненської міської ради: https://rivnerada.gov.ua/PublicServicesAPI/api/search-document/load-senate-document/22316/0/27/24-12-2020.
# Уточнення точок на мапі

Після створення тестових даних можна прив'язати товари до будинків через вже підключений HERE:

`node backend/scripts/geocode-rivne-demo.mjs --apply`

Без `--apply` команда тільки перевіряє адреси. Потрібен наявний ключ HERE у `.env` або `frontend/.env.local`. Команда змінює лише координати тестових товарів; приватні адреси справжніх користувачів не змінює.
