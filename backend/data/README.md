# Населені пункти України

`settlements.json` — усі 29 703 населені пункти офіційного КАТОТТГ від 07.07.2026.
Джерело: [Міністерство розвитку громад та територій України](https://mininfra.gov.ua/diialnist/rozvytok-mistsevoho-samovriaduvannia/kodyfikator-administratyvno-terytorialnykh-odynyts-ta-terytorii-terytorialnykh-hromad).
URL та SHA-256 оригіналу записані в JSON. Дані державного довідника; джерело збережене для атрибуції.

Відтворення: `python backend/scripts/import-settlements.py backend/data/katottg-source.xlsx`.
Нових залежностей не потрібно. Під час оновлення змініть дату версії в імпортері, перевірте перейменування та видалені коди; наявні адреси не переписуйте автоматично.

Категорії M/K → місто, T/X → селище, C → село. Київ і Севастополь не мають району рівня області: порожній район не вигадується. Громада збережена для розрізнення однакових назв в одному районі.
